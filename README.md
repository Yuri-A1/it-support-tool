# 🛠️ IT Support & Network Diagnostic Tool

Script en Python diseñado para técnicos de soporte Helpdesk L1/L2. Permite recopilar rápidamente la información básica del equipo y realizar diagnósticos de conectividad de red para agilizar la resolución de incidencias.

## 📋 Funcionalidades
- **Información del Sistema:** Detecta versión del SO, arquitectura y nombre de red del equipo.
- **Detección de IP Local:** Identifica la interfaz de red activa.
- **Resolución DNS:** Verifica si el servicio DNS está respondiendo contra servidores externos.
- **Prueba de Salida a Internet:** Comprueba la comunicación mediante paquetes ICMP (Ping).

## 🚀 Requisitos y Ejecución
No requiere instalación de librerías externas (funciona con la biblioteca estándar de Python).
